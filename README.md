# PrintKit Studio

Bambu Lab A1 miniの180 × 180 × 180 mm造形範囲に特化し、寸法を入力して可動機構や便利ガジェットをSTL形式で生成できるWebアプリです。

## できること

- ネスト・スピナー：一体印刷できる同心リングのフィジェット
- 一体型ピボット蝶番：ピンと交互ナックルを一度に印刷
- かみ合い歯車ペア：歯数・モジュール・軸穴・すき間を指定
- オープンボックス：幅・奥行き・高さ・壁厚を指定
- ケーブルクリップ：ケーブル径・肉厚・幅・開口角を指定
- スペーサー：内径・外径・高さを指定
- ドアストッパー：長さ・幅・高さを指定
- 生成モデルの3Dプレビューとドラッグ回転
- ブラウザ内でバイナリSTLを生成・ダウンロード
- 材料使用量と印刷時間の簡易見積もり
- A1 miniの造形範囲、ノズル径別の推奨クリアランス、プレート使用率を表示

寸法とSTLデータは端末内で処理され、サーバーには送信されません。

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## 注意

印刷前にスライサーでモデル、造形方向、充填率、サポート、プリンタの造形範囲を確認してください。
