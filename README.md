# PrintKit Studio

寸法を入力して、3Dプリンタ向けの便利ガジェットをSTL形式で生成できるWebアプリです。

## できること

- オープンボックス：幅・奥行き・高さ・壁厚を指定
- ケーブルクリップ：ケーブル径・肉厚・幅・開口角を指定
- スペーサー：内径・外径・高さを指定
- ドアストッパー：長さ・幅・高さを指定
- 生成モデルの3Dプレビューとドラッグ回転
- ブラウザ内でバイナリSTLを生成・ダウンロード
- 材料使用量と印刷時間の簡易見積もり

寸法とSTLデータは端末内で処理され、サーバーには送信されません。

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## 注意

印刷前にスライサーでモデル、造形方向、充填率、サポート、プリンタの造形範囲を確認してください。
